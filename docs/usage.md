# Schritt für Schritt

## Text schreiben

1. Widget auf der Seite einfügen. Der Konfigurationsdialog öffnet sich, und
   der Editor erscheint sofort als großes Fenster.
2. Text schreiben. Der Editor verhält sich wie ein Textverarbeitungsprogramm:
   Eingabetaste beginnt einen neuen Absatz, Umschalt+Eingabe eine neue Zeile
   im selben Absatz.
3. Oben links das **Absatzformat** wählen — Fließtext, Überschrift 1 bis 3
   oder Zitat. Es gilt für den Absatz, in dem die Schreibmarke steht.
4. Text markieren und über **F**, **K**, **U**, **S** oder **</>** fett,
   kursiv, unterstrichen, durchgestrichen oder als Code auszeichnen.
   Tastenkürzel: Strg+B, Strg+I, Strg+U.
5. **Speichern** oben rechts. Danach schließt das Fenster; über **Inhalt
   bearbeiten** kommen Sie zurück.
6. Den Konfigurationsdialog wie gewohnt bestätigen und die Seite
   veröffentlichen.

## Aufzählung anlegen

Schreibmarke in den Absatz setzen und **Liste** (Punkte) oder **1. Liste**
(Nummern) drücken. Eingabetaste legt den nächsten Punkt an, Tabulator rückt
einen Punkt eine Ebene ein, Umschalt+Tabulator wieder heraus. Zweimal die
Eingabetaste beendet die Liste.

## Verweis setzen

1. Den Text markieren, der zum Verweis werden soll.
2. **Verweis** drücken. Adresse eintragen — vollständig mit `https://`.
3. **Einfügen**.

Zum Entfernen die Schreibmarke in den Verweis setzen und **Verweis lösen**
drücken.

## Wenn etwas nicht gespeichert wurde

Solange ungespeicherte Änderungen offen sind, steht **Nicht gespeichert** in
der Werkzeugleiste. Wer das Fenster dann schließt, wird gefragt, ob die
Änderungen verworfen werden sollen.
