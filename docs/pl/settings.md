# Ustawienia

Widżet ma tylko jedno ustawienie — wszystko inne odbywa się w edytorze.

| Ustawienie | Opis |
| --- | --- |
| Treść | Sformatowany tekst. Jest on edytowany w edytorze, a nie wpisywany ręcznie; przycisk **Edytuj treść** ponownie go otwiera. |

## Możliwości edytora

Pasek narzędzi **Format**, od lewej do prawej:

| Narzędzie | Efekt |
| --- | --- |
| Format akapitu | Tekst ciągły, nagłówek 1–6, cytat, blok kodu — dotyczy akapitu w miejscu kursora. |
| Pogrubienie, kursywa, podkreślenie, przekreślenie, kod | Dotyczy zaznaczonego tekstu. |
| … (Inne formatowania) | Wyróżnienie, indeks górny, indeks dolny, symbol; opcja „Usuń formatowanie” usuwa wszystkie formatowania. |
| Wypunktowanie, lista numerowana | Lista z punktami lub numerami, z możliwością wcięcia za pomocą klawisza Tab. |
| Wcięcie, wysunięcie | Stopniowo wciąga lub wysuwa akapity, nagłówki i cytaty. |
| Wyrównanie | W lewo, wyśrodkowane, w prawo, wyjustowane — dotyczy akapitu w miejscu kursora. |
| Wstaw linię oddzielającą | Wstawia poziomą linię. |
| Link, Usuń link | Ustawia, zmienia lub usuwa link w zaznaczonym tekście. |
| Rozmiar czcionki | Od 12 do 72 pikseli; 16 to rozmiar tekstu bieżącego. |
| Kolor tekstu, tło tekstu | Jeden z dwunastu stałych kolorów lub „Standard”. |

Opcje „Zastosuj”, „Anuluj”, „Cofnij”, „Powtórz” oraz „Pomoc” znajdują się w nagłówku
okna, tak jak we wszystkich widżetach MAN.

Czcionki, nagłówki i odstępy pochodzą z projektu MAN:
nagłówek wygląda wszędzie tak samo, niezależnie od tego, kto go napisał
.
