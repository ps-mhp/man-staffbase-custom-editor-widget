# Ustawienia

Widżet ma dokładnie jedno ustawienie — wszystko inne dzieje się w edytorze. 

| Miejsce akcji | Opis |
| --- | --- |
| Treść | Sformatowany tekst. Utrzymywany za pomocą przycisku **Edytuj treść** w edytorze, nie wpisany jako tekst. |

## Co redaktor może zrobić

| Narzędzie | Wpływ |
| --- | --- |
| Format akapitu | Tekst ciągły, nagłówek 1-3, cudzysłów — dotyczy akapitu na znaku pisma. |
| F / K / U / S / ''<!----> | Pogrubione, kursywa, podkreślone, przekreślone, kod — dotyczy wybranego tekstu. |
| Lista / 1. lista | Lista z kropkami lub cyframi, wycięte tabulatorem. |
| Wyrównanie | Wyrównanie w lewo, wyśrodkowanie, wyrównanie w prawo, justowanie — dotyczy akapitu na znaku pisania. |
| Odniesienie / Odłączenie odniesienia | Ustawia lub usuwa odniesienie z wybranego tekstu. |
| Linia dzieląca | Wstawia linię poziomą. |

Wygląd i kolory pochodzą z projektu MAN i celowo nie mogą być
Ustaw indywidualnie: nagłówek wygląda tak samo wszędzie, niezależnie od
kto ją napisał.
