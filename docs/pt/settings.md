# Configurações

O widget tem exatamente uma configuração — todo o resto acontece no editor. 

| Cenário | Descrição |
| --- | --- |
| Conteúdo | O texto formatado. Mantido pelo botão **Editar conteúdo** no editor, não digitado como texto. |

## O que o editor pode fazer

| Ferramenta | Impacto |
| --- | --- |
| Formato do parágrafo | Texto contínuo, cabeçalho 1-3, aspas — aplica-se ao parágrafo na marca de escrita. |
| F / K / U / S / ''<!----> | Negrito, itálico, sublinhado, riscado, código — aplica-se ao texto selecionado. |
| Lista / 1ª lista | Lista com pontos ou números, indentável com tabulação. |
| Alinhamento | Alinhado à esquerda, centralizado, alinhado à direita, justificado — aplica-se ao parágrafo na marca de escrita. |
| Referência / Referência Separada | Define ou remove uma referência no texto selecionado. |
| Linha divisória | Insere uma linha horizontal. |

O visual e as cores vêm do design MAN e deliberadamente não podem ser
Um Individualmente: Uma manchete parece igual em todos os lugares, independentemente do
de quem a escreveu.
