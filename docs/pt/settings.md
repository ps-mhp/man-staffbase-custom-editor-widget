# Configurações

O widget tem exatamente uma configuração — tudo o resto é feito no editor.

| Configuração | Descrição |
| --- | --- |
| Conteúdo | O texto formatado. É editado no editor, não é digitado como texto; o botão **Editar conteúdo** reabre-o. |

## O que o editor permite fazer

A barra de ferramentas **Formato**, da esquerda para a direita:

| Ferramenta | Efeito |
| --- | --- |
| Formato do parágrafo | Texto corrido, título 1–6, citação, bloco de código — aplica-se ao parágrafo na posição do cursor. |
| Negrito, itálico, sublinhado, riscado, código | Aplica-se ao texto selecionado. |
| … (Outras formatações) | Destacado, sobrescrito, subscrito, símbolo; «Remover formatação» elimina todas as formatações. |
| Enumerado, Lista numerada | Lista com pontos ou números, com recuo por tabulação. |
| Recuar, avançar | Recua ou avança parágrafos, títulos e citações gradualmente. |
| Alinhamento | Alinhado à esquerda, centrado, alinhado à direita, justificado — aplica-se ao parágrafo na posição do cursor. |
| Inserir linha divisória | Inserir uma linha horizontal. |
| Link, Remover link | Cria, altera ou remove um link no texto selecionado. |
| Tamanho da fonte | 12 a 72 píxeis; 16 é o tamanho padrão para texto corrido. |
| Cor do texto, fundo do texto | Uma das doze cores predefinidas ou «Padrão». |

Aplicar, Cancelar, Voltar atrás, Repetir e a Ajuda encontram-se no cabeçalho
da janela, tal como em todos os widgets MAN.

Os tipos de letra, os títulos e os espaçamentos provêm do design MAN: um
título tem sempre o mesmo aspeto, independentemente de quem o tenha escrito
.
