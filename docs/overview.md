# Editor

Das Widget stellt formatierten Fließtext auf eine Seite: Überschriften,
Absätze, Aufzählungen, Zitate, Verweise und Trennlinien. Gedacht ist es für
alles, was mehr Struktur braucht als eine einzelne Textzeile, aber kein
eigenes Widget rechtfertigt — Erklärstrecken, Hinweistexte, Merkblätter.

Geschrieben wird in einem Editor, der genauso aussieht wie das Ergebnis: die
Schreibfläche benutzt dieselben Schriften, Größen und Abstände wie die
veröffentlichte Seite. Was im Editor eine Überschrift ist, ist auf der Seite
eine Überschrift — es gibt keine zweite Formatierungsebene, die davon
abweichen könnte.

Der Text wird als Struktur gespeichert, nicht als fertiges HTML. Deshalb zieht
er eine Änderung am MAN-Design automatisch nach, ohne dass jemand die Inhalte
anfassen muss.

## Was Leser:innen sehen

Den formatierten Text, eingebettet in die Seite. Ohne Rahmen, ohne Kasten,
ohne Überschrift des Widgets selbst — das Widget bringt nur seinen Inhalt mit.

Ist nichts eingetragen, erscheint auf der Seite gar nichts. Ein leeres Widget
hinterlässt also keine Lücke.

## Was Sie im CMS-Editor sehen

Statt eines Textfeldes den Knopf **Inhalt bearbeiten**. Er öffnet den Editor
als großes Fenster über dem Dialog.
