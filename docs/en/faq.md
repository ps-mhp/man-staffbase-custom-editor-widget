# FAQ

## Can I insert text from Word? 

Yes. Structure and markups that the widget knows — headings, 
Bulleted lists, bold, italics — will be copied. Everything else (fonts, 
Colors, sizes from Word) is omitted so that the text follows the MAN design. 

## Why can't I choose a font or color? 

Because both are defined in the MAN design. A text that has its own font
falls out of the page as soon as the design is adjusted. 

## Is there a length limit? 

Practically not for continuous text. The limit is for the entire contribution, not
widget, and was measured at around 16 million characters — that's
several thousand book pages. 

## Can I insert images? 

No. For images, use the image widget from Staffbase or the
Table that can take pictures into cells. 

## The text looks different on the page than it does in the editor. 

This should not happen — editor and page use the same set of rules. 
If you do, first check if the page has already been republished. 
and otherwise report it with a screenshot of both views. 

## I accidentally deleted everything. 

As long as the editor window is open: Ctrl+Z. Is already saved and the
Dialog closed, only the version history of the page in Staffbase helps.
