# FAQ

## Can I paste text from Word?

Yes. The widget recognizes and preserves formatting and structure—headings,
bulleted lists, bold, and italics. Everything else (such as fonts
from Word) is removed so that the text conforms to the MAN design.

## Why can’t I choose a font or any color I want?

The font is specified by the MAN design: text that includes its own font
will no longer fit on the page as soon as the design is adjusted.
You can set the size, text color, and text background, but colors are limited to
a fixed selection of twelve shades.

## Why isn’t there a preview like with other widgets?

Because the page in the editor is already the preview: it uses the same
fonts, sizes, and spacing as the published page.

## Is there a length limit?

Practically none for continuous text. The limit applies to the entire post, not
the widget, and has been measured at around 16 million characters—that’s
several thousand book pages.

## Can I insert images?

No. For images, use the Staffbase Image widget or the
table, which can contain images in cells.

## The text looks different on the page than it does in the editor.

This shouldn’t happen—the editor and the page use the same formatting rules.
If it does, first check whether the page has already been republished,
and if not, please report it with a screenshot of both views.

## I accidentally deleted everything.

As long as the editor window is open: ⌘/Ctrl+Z in the text or **Undo** in the
header. Haven’t saved yet? Then **Cancel** will discard everything since the
last save. If it’s already been saved and the dialog is closed, the only option is
to check the page’s version history in Staffbase.

## Does simply opening the editor change my text?

No. If you open the editor and close it without making any changes or saving,
nothing is written: **Save** won’t be triggered as long as nothing has been changed, and
the block on the page remains as it was.
