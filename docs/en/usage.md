# Step by Step

## Writing Text

1. Insert the widget onto the page. The configuration dialog opens, and
   the editor immediately appears as a full-screen window.
2. Write text. The editor works like a word processor:
   Pressing Enter starts a new paragraph; Shift+Enter starts a new line
   within the same paragraph.
3. Select the **Paragraph Format** at the front of the toolbar—body text,
   heading 1 through 6, quote, or code block. This applies to the paragraph where
   the text cursor is located.
4. Select text and format it using **Bold**, **Italic**, **Underline**,
   **Strikethrough**, or **Code**. Keyboard shortcuts: ⌘/Ctrl B,
   ⌘/Ctrl I, ⌘/Ctrl U. Highlight, superscript, subscript, symbol, and
   “Remove Formatting” are located behind **…** next to them.
5. Click **Apply** (⌘/Ctrl S) in the upper-right corner. The window will then close; click
   **Edit Content** to return.
6. Confirm the configuration dialog as usual, then save
   and publish the page. “Apply” only updates the dialog—changes
   are not saved until you click “Save” in Studio.

## Creating a Bulleted List

Place the cursor in the paragraph and select **Bulleted List** (bullets) or
**Numbered List** (numbers). The Enter key creates the next item,
the Tab key indents an item one level, and Shift+Tab moves it out one level.
Pressing the Enter key twice ends the list. **Indent** and **Outdent**
also indent or outdent paragraphs, headings, and quotes in stages.

## Insert a link

1. Select the text you want to turn into a link.
2. Select **Link**. A toolbar opens on the right.
3. Enter the **address**—in full with `https://`, or `mailto:` or
   `tel:`. The field does not allow other formats and will notify you immediately if they are incorrect.
4. Adjust the **text** as needed and select **Insert Link**.

If the text cursor is already inside a link, the same tool opens it for
editing. To remove it, place the text cursor inside the link and select **Remove
Link**; the text remains unchanged.

## Size and Color

At the end of the toolbar are **Font Size**, **Text Color**, and
**Text Background**. The colors come from a fixed selection of twelve
shades; **Default** resets the color to the default.

## Undo

If the cursor is in the text, ⌘/Ctrl Z undoes the last action.
**Undo** and **Redo** at the top cycle through all
states since the document was opened.

## If a change wasn’t saved

As long as changes are pending, **Text changed – not
saved** appears next to the title. If you close the window at this point, you’ll be asked whether to
save or discard the changes. If you simply click inside without making any
changes, there’s nothing to save—the block remains unchanged.
