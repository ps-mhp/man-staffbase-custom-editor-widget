# Step by step

## Write text

1. Insert the widget on the page. The configuration dialog opens, and
   the editor immediately appears as a large window. 
2. Write text. The editor behaves like a word processor: 
   Enter starts a new paragraph, Shift+Enter starts a new line
   in the same paragraph. 
3. Select the **paragraph style** in the top left corner — body text, heading 1 to 3
   or quotation. It applies to the paragraph in which the writing mark appears. 
4. Select text and bold it over **F**, **K**, **U**, **S** or **<!---->**, 
   italics, underlined, strikethrough, or mark up as code. 
   Shortcuts: Ctrl+B, Ctrl+I, Ctrl+U. 
5. **Save** in the top right. After that, the window closes; via **Content
   edit** come back. 
6. Confirm the configuration dialog as usual and open the page
   . 

## Create a bulleted list

Put the pen mark in the paragraph and **List** (points) or **1st list** 
(Numbers). Enter key creates the next point, tab moves
one point one level, Shift+Tab out again. Twice the
Enter closes the list. 

## Reference

1. Select the text that is to become a reference. 
2. Press **Reference**. Enter the address — complete with 'https://'. 
3. **Insert**. 

To remove, place the writing mark in the reference and **Unlink link** 
. 

## If something has not been saved

As long as unsaved changes are open, **Not saved** in
toolbar. If you then close the window, you will be asked whether the
changes are to be discarded.
