# Ajustes

El widget tiene un único ajuste; todo lo demás se configura en el editor.

| Ajuste | Descripción |
| --- | --- |
| Contenido | El texto formateado. Se gestiona en el editor, no se escribe directamente como texto; el botón **Editar contenido** lo vuelve a abrir. |

## Funciones del editor

La barra de herramientas **Formato**, de izquierda a derecha:

| Herramienta | Efecto |
| --- | --- |
| Formato de párrafo | Texto continuo, título 1–6, cita, bloque de código — se aplica al párrafo en el que se encuentra el cursor. |
| Negrita, cursiva, subrayado, tachado, código | Se aplica al texto seleccionado. |
| … (Otros estilos) | Destacado, superíndice, subíndice, símbolo; «Quitar formato» elimina todos los estilos. |
| Lista con viñetas, lista numerada | Lista con viñetas o números, se puede sangrar con la tecla Tab. |
| Sangrar, desangrar | Sangra o desangra párrafos, títulos y citas de forma escalonada. |
| Alineación | Alineado a la izquierda, centrado, alineado a la derecha, justificado — se aplica al párrafo en el que se encuentra el cursor. |
| Insertar línea divisoria | Inserta una línea horizontal. |
| Enlace, Eliminar enlace | Establece, modifica o elimina un enlace en el texto seleccionado. |
| Tamaño de fuente | De 12 a 72 píxeles; 16 es el tamaño predeterminado para el texto corrido. |
| Color del texto, fondo del texto | Uno de los doce colores fijos, o «Estándar». |

Aplicar, Cancelar, Deshacer, Rehacer y Ayuda se encuentran en la parte superior
de la ventana, al igual que en todos los widgets de MAN.

Las fuentes, los títulos y los espacios se basan en el diseño de MAN: un
título tiene el mismo aspecto en todas partes, independientemente de quién lo haya escrito
.
