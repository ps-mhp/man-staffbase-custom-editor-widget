# Paso a paso

## Escribir texto

1. Inserta el widget en la página. Se abrirá el cuadro de diálogo de configuración y
   el editor aparecerá inmediatamente como una ventana a pantalla completa.
2. Escribe el texto. El editor funciona como un procesador de textos:
   la tecla Intro inicia un nuevo párrafo, y Mayús+Intro, una nueva línea
   dentro del mismo párrafo.
3. Selecciona el **formato de párrafo** en la barra de herramientas de la parte superior: texto continuo,
   título 1 a 6, cita o bloque de código. Se aplica al párrafo en el que
   se encuentra el cursor.
4. Selecciona el texto y aplica **negrita**, **cursiva**, **subrayado**,
   **tachado** o **código**. Atajos de teclado: ⌘/Ctrl B,
   ⌘/Ctrl B, ⌘/Ctrl I, ⌘/Ctrl U. Las opciones de resaltado, superíndice y subíndice, la tecla y
   «Quitar formato» aparecen detrás de **…** junto a ellas.
5. En la esquina superior derecha, haz clic en **Aplicar** (⌘/Ctrl S). A continuación, se cierra la ventana; mediante
   **Editar contenido** puede volver atrás.
6. Confirme el cuadro de diálogo de configuración como de costumbre y guarde
   y publique la página. «Aplicar» solo escribe en el cuadro de diálogo; el cambio
   solo se guarda con «Guardar» en Studio.

## Crear una lista

Coloca el cursor en el párrafo y selecciona **Lista con viñetas** (puntos) o
**Lista numerada** (números). La tecla Intro crea el siguiente punto,
la tecla Tabulação desplaza un punto hacia dentro y Mayús+Tabulação, hacia fuera.
Pulsar dos veces la tecla Intro finaliza la lista. **Ajustar hacia dentro** y **ajustar hacia fuera**
también permiten ajustar gradualmente hacia dentro los párrafos, los títulos y las citas.

## Insertar un enlace

1. Selecciona el texto que quieres convertir en enlace.
2. Selecciona **Enlace**. Se abrirá una barra a la derecha.
3. Introduce la **dirección** —completa con `https://`, o `mailto:` o
   `tel:`. El campo no admite otros esquemas y lo indica inmediatamente.
4. Modifica el **texto** si es necesario y selecciona **Insertar enlace**.

Si el cursor ya se encuentra dentro de un enlace, esta misma herramienta lo abre para
modificarlo. Para eliminarlo, coloca el cursor dentro del enlace y selecciona **Eliminar
enlace**; el texto se mantiene.

## Tamaño y color

Al final de la barra se encuentran **Tamaño de fuente**, **Color del texto** y
**Fondo del texto**. Los colores proceden de una selección fija de doce
tonos; **Predeterminado** restablece el color predeterminado.

## Deshacer

Si el cursor está en el texto, ⌘/Ctrl+Z deshace la última acción.
**Deshacer** y **Rehacer**, en la parte superior, recorren paso a paso todos los
estados desde que se abrió el documento.

## Si no se han aplicado los cambios

Mientras haya cambios pendientes, aparecerá junto al título **Texto modificado – no
aplicado**. Si se cierra la ventana en ese momento, se preguntará si se deben
aplicar o descartar los cambios. Si solo se hace clic en ella sin modificar nada,
no hay nada que aplicar: el bloque permanece sin cambios.
