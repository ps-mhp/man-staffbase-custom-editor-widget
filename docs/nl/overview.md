# Redacteur

De widget plaatst opgemaakte hoofdtekst op een pagina: koppen, 
Paragrafen, opsommingstekens, citaten, referenties en scheidslijnen. Het is bedoeld voor
Alles wat meer structuur nodig heeft dan een enkele regel tekst, maar nee
Eigen widget — verklarende secties, informatieteksten, folders. 

Het schrijven gebeurt in een editor die er precies zo uitziet als het resultaat: de
Schrijfoppervlak gebruikt dezelfde lettertypen, groottes en spatiëring als de
gepubliceerde pagina. Wat een kop in de editor is, staat op de pagina
Een kop — er is geen tweede opmaakniveau dat gebruikt kan worden om
kan afwijken. 

De tekst wordt opgeslagen als structuur, niet als afgewerkte HTML. Daarom
maakt automatisch een wijziging aan het MAN-ontwerp zonder dat iemand de inhoud van de
. 

## Wat lezers zien

De opgemaakte tekst, ingebed in de pagina. Zonder kaders, zonder vakken, 
Zonder de kop van de widget zelf — brengt de widget alleen zijn inhoud. 

Als er niets wordt ingevoerd, verschijnt er niets op de pagina. Een lege widget
Dus er blijft geen opening achter. 

## Wat je ziet in de CMS-editor

In plaats van een tekstveld druk je op de **Inhoud bewerken**-knop. Dan opent je de editor
als een groot venster boven de dialoog.
