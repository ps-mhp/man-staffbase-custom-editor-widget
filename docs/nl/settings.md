# Instellingen

De widget heeft precies één instelling — al het andere gebeurt in de editor.

| Instelling | Beschrijving |
| --- | --- |
| Inhoud | De opgemaakte tekst. Wordt in de editor bewerkt, niet als tekst ingetypt; de knop **Inhoud bewerken** opent deze weer. |

## Wat de editor kan

De werkbalk **Opmaak**, van links naar rechts:

| Gereedschap | Effect |
| --- | --- |
| Alinea-opmaak | Looptekst, kop 1–6, citaat, codeblok — geldt voor de alinea bij de tekstmarkering. |
| Vet, cursief, onderstreept, doorgestreept, code | Geldt voor de gemarkeerde tekst. |
| … (Overige opmaakopties) | Gemarkeerd, superscript, subscript, symbool; ‘Opmaak verwijderen’ verwijdert alle opmaak. |
| Opsomming, genummerde lijst | Lijst met punten of nummers, inspringen met tab. |
| Inspringen, uitspringen | Laat alinea’s, koppen en citaten stapsgewijs inspringen of uitspringen. |
| Uitlijning | Links uitgelijnd, gecentreerd, rechts uitgelijnd, blokuitlijning — geldt voor de alinea bij de tekstmarkering. |
| Scheidingslijn invoegen | Voegt een horizontale lijn in. |
| Link, Link verwijderen | Plaatst, wijzigt of verwijdert een link op de gemarkeerde tekst. |
| Lettergrootte | 12 tot 72 pixels; 16 is de standaardgrootte voor lopende tekst. |
| Tekstkleur, tekstachtergrond | Een van de twaalf vaste kleuren, of „Standaard“. |

Toepassen, Annuleren, Ongedaan maken, Herhalen en de Help staan bovenaan
het venster, net als bij alle MAN-widgets.

Lettertypen, koppen en afstanden zijn afkomstig uit het MAN-ontwerp: een
kop ziet er overal hetzelfde uit, ongeacht wie deze heeft geschreven
.
