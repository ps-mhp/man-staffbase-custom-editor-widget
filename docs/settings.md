# Einstellungen

Das Widget hat genau eine Einstellung — alles Weitere passiert im Editor.

| Einstellung | Beschreibung |
| --- | --- |
| Inhalt | Der formatierte Text. Wird über den Knopf **Inhalt bearbeiten** im Editor gepflegt, nicht als Text eingetippt. |

## Was der Editor kann

| Werkzeug | Wirkung |
| --- | --- |
| Absatzformat | Fließtext, Überschrift 1-3, Zitat — gilt für den Absatz an der Schreibmarke. |
| F / K / U / S / `</>` | Fett, kursiv, unterstrichen, durchgestrichen, Code — gilt für den markierten Text. |
| Liste / 1. Liste | Aufzählung mit Punkten oder Nummern, mit Tabulator einrückbar. |
| Ausrichtung | Linksbündig, zentriert, rechtsbündig, Blocksatz — gilt für den Absatz an der Schreibmarke. |
| Verweis / Verweis lösen | Setzt oder entfernt einen Verweis auf dem markierten Text. |
| Trennlinie | Fügt eine waagerechte Linie ein. |

Aussehen und Farben kommen aus dem MAN-Design und lassen sich bewusst nicht
einzeln einstellen: eine Überschrift sieht überall gleich aus, unabhängig
davon, wer sie geschrieben hat.
