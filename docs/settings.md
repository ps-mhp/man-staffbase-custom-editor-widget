# Einstellungen

Das Widget hat genau eine Einstellung — alles Weitere passiert im Editor.

| Einstellung | Beschreibung |
| --- | --- |
| Inhalt | Der formatierte Text. Wird im Editor gepflegt, nicht als Text eingetippt; der Knopf **Inhalt bearbeiten** öffnet ihn wieder. |

## Was der Editor kann

Die Werkzeugleiste **Format**, von links nach rechts:

| Werkzeug | Wirkung |
| --- | --- |
| Absatzformat | Fließtext, Überschrift 1–6, Zitat, Codeblock — gilt für den Absatz an der Schreibmarke. |
| Fett, Kursiv, Unterstrichen, Durchgestrichen, Code | Gilt für den markierten Text. |
| … (Weitere Auszeichnungen) | Hervorgehoben, hochgestellt, tiefgestellt, Taste; „Formatierung entfernen“ nimmt alle Auszeichnungen weg. |
| Aufzählung, Nummerierte Liste | Liste mit Punkten oder Nummern, mit Tab einrückbar. |
| Ausrücken, Einrücken | Rückt Absätze, Überschriften und Zitate stufenweise ein oder aus. |
| Ausrichtung | Linksbündig, zentriert, rechtsbündig, Blocksatz — gilt für den Absatz an der Schreibmarke. |
| Trennlinie einfügen | Fügt eine waagerechte Linie ein. |
| Link, Link entfernen | Setzt, ändert oder entfernt einen Link auf dem markierten Text. |
| Schriftgröße | 12 bis 72 Pixel; 16 ist der Fließtext. |
| Textfarbe, Texthintergrund | Eine von zwölf festen Farben, oder „Standard“. |

Übernehmen, Abbrechen, Rückgängig, Wiederholen und die Hilfe stehen im Kopf
des Fensters, wie bei allen MAN-Widgets.

Schriften, Überschriften und Abstände kommen aus dem MAN-Design: eine
Überschrift sieht überall gleich aus, unabhängig davon, wer sie geschrieben
hat.
