# Décors

Le widget n’a qu’un seul réglage — tout le reste se passe dans l’éditeur. 

| Cadre | Description |
| --- | --- |
| Contenu | Le texte formaté. Maintenu via le bouton **Modifier le contenu** dans l’éditeur, non tapé en texte. |

## Ce que l’éditeur peut faire

| Outil | Impact |
| --- | --- |
| Format du paragraphe | Texte continu, titres 1-3, citation — s’applique au paragraphe sur la marque d’écriture. |
| F / K / U / S / ''<!----> Gras, italique, souligné, rayé, code — s’applique au texte sélectionné. |
| Liste / 1ère liste | Liste avec points ou chiffres, indentable avec tabulation. |
| Alignement | Aligné à gauche, centré, aligné à droite, justifié — s’applique au paragraphe sur la marque d’écriture. |
| Référence / Détachement Référence | Établit ou supprime une référence sur le texte sélectionné. |
| Ligne de démarcation | Insère une ligne horizontale. |

L’apparence et les couleurs viennent du design MAN et ne peuvent pas être délibérément
Un seul : un titre est identique partout, peu importe le
de qui l’a écrit.
