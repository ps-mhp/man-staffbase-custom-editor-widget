# Paramètres

Le widget ne comporte qu'un seul paramètre — tout le reste se fait dans l'éditeur.

| Paramètre | Description |
| --- | --- |
| Contenu | Le texte mis en forme. Il est géré dans l’éditeur, et non saisi sous forme de texte ; le bouton **Modifier le contenu** permet de l’ouvrir à nouveau. |

## Fonctionnalités de l’éditeur

La barre d’outils **Format**, de gauche à droite :

| Outil | Effet |
| --- | --- |
| Format de paragraphe | Texte courant, titre 1 à 6, citation, bloc de code — s’applique au paragraphe situé au niveau du curseur. |
| Gras, italique, souligné, barré, code | S’applique au texte sélectionné. |
| … (Autres formats) | Mis en évidence, exposant, indice, touche ; « Supprimer la mise en forme » supprime tous les formats. |
| Liste à puces, liste numérotée | Liste avec des puces ou des numéros, indentable à l’aide de la touche Tab. |
| Retrait, indentation | Permet de mettre en retrait ou d’indenter progressivement les paragraphes, les titres et les citations. |
| Alignement | Aligné à gauche, centré, aligné à droite, justifié — s’applique au paragraphe situé au niveau du curseur. |
| Insérer une ligne de séparation | Insère une ligne horizontale. |
| Lien, Supprimer le lien | Crée, modifie ou supprime un lien sur le texte sélectionné. |
| Taille de police | De 12 à 72 pixels ; 16 correspond au texte courant. |
| Couleur du texte, arrière-plan du texte | L’une des douze couleurs prédéfinies, ou « Standard ». |

Les boutons Appliquer, Annuler, Annuler la dernière action, Répéter et Aide se trouvent en haut
de la fenêtre, comme pour tous les widgets MAN.

Les polices, les titres et les espacements proviennent du design MAN : un
titre a le même aspect partout, quel que soit son auteur
.
