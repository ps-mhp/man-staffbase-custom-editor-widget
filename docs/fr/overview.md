# Rédacteur en chef

Le widget place le texte de corps formaté sur une page : titres, 
Paragraphes, listes à puces, citations, références et lignes de démarcation. Il est destiné à
Tout ce qui nécessite plus de structure qu’une seule ligne de texte, mais non
Widget propre — sections explicatives, textes d’information, brochures.

La surface d’écriture utilise les mêmes polices, tailles et espacements que la
page publiée. Ce qu’est un titre dans l’éditeur se trouve sur la page
un titre — il n’existe pas de second niveau de mise en forme pouvant être utilisé pour
pourrait dévier. 

Le texte est enregistré sous forme de structure, pas sous forme de HTML fini. C’est pourquoi
effectue automatiquement une modification du design MAN sans que personne n’ait à modifier le contenu du

## Ce que voient les lecteurs

Le texte formaté, intégré dans la page. Sans cadres, sans encadrés, 
Sans l’en-tête du widget lui-même — le widget ne propose que son contenu. 

Si rien n’est saisi, rien n’apparaît sur la page. Un widget vide
Donc il ne laisse pas de vide. 

## Ce que vous voyez dans l’éditeur CMS

Au lieu d’un champ de texte, appuyez sur le bouton **Modifier le contenu**. Cela ouvre l’éditeur
comme une grande fenêtre au-dessus du dialogue.
