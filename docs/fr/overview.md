# Éditeur

Ce widget permet d'afficher du texte continu formaté sur une page : titres,
paragraphes, listes à puces, citations, références et lignes de séparation. Il est destiné à
tout ce qui nécessite davantage de structure qu’une simple ligne de texte, mais qui ne justifie pas
la création d’un widget dédié : explications, notes d’information, fiches pratiques.

La rédaction s’effectue dans un éditeur qui ressemble exactement au résultat final : la
zone de rédaction utilise les mêmes polices, tailles et espacements que la
page publiée. Ce qui est un titre dans l’éditeur est un titre sur la page
— il n’y a pas de deuxième niveau de mise en forme qui pourrait
s’en écarter.

Le texte est enregistré sous forme de structure, et non sous forme de code HTML fini. C’est pourquoi
il s’adapte automatiquement à toute modification apportée au design MAN, sans que quiconque ait à
modifier le contenu.

## Ce que voient les lectrices et lecteurs

Le texte formaté, intégré à la page. Sans cadre, sans encadré,
sans titre du widget lui-même — le widget n’apporte que son contenu.

Si rien n’est saisi, rien n’apparaît sur la page. Un widget vide
ne laisse donc pas de vide.

## Ce que vous voyez dans l’éditeur du CMS

L’éditeur s’ouvre en plein écran au-dessus de la boîte de dialogue, dans le même cadre
que tous les widgets MAN : en haut, l’en-tête avec **Annuler**, **Appliquer**,
Annuler, Répéter et Aide ; en dessous, la barre d’outils **Format** et
le texte sur une feuille occupant toute la largeur de la page. Il n’y a pas d’aperçu séparé :
la feuille affiche déjà le texte tel qu’il apparaîtra sur la page.

Dans la boîte de dialogue elle-même se trouve ensuite le bouton **Modifier le contenu**, qui
rouvre la fenêtre.
