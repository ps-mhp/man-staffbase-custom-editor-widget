# Pas à pas

## Écrire du texte

1. Insérer le widget sur la page. La boîte de dialogue de configuration s’ouvre, et
   l’éditeur apparaît immédiatement sous forme de grande fenêtre. 
2. Écrire du texte. L’éditeur se comporte comme un traitement de texte : 
   Entrée commence un nouveau paragraphe, Majus+Entrée commence une nouvelle ligne
   dans le même paragraphe. 
3. Sélectionnez le **style de paragraphe** en haut à gauche — texte du corps, titre 1 à 3
   ou une citation. Elle s’applique au paragraphe où apparaît la marque d’écriture. 
4. Sélectionnez du texte et mettez-le en gras sur **F**, **K**, **U**, **S** ou **<!---->**, 
   en italique, souligné, rayé, ou marquage en code. 
   Raccourcis : Ctrl+B, Ctrl+I, Ctrl+U. 
5. **Enregistrer** en haut à droite. Après cela, la fenêtre se ferme ; via **Contenu
   Édit** Revenez. 
6. Confirmez la boîte de configuration comme d’habitude et ouvrez la page
   . 

## Créez une liste à puces

Mettez la marque au stylo dans le paragraphe et **List** (points) ou **1ère liste** 
(Nombres). La touche Entrée crée le point suivant, la tabulation bouge
un point un niveau, Shift + Tab à nouveau. Deux fois le
Entrer ferme la liste. 

## Référence

1. Sélectionner le texte qui deviendra une référence. 
2. Appuyez sur **Référence**. Entrez l’adresse — avec 'https://'. 
3. **Insérer**. 

Pour retirer, placez la marque d’écriture dans la référence et **Désassocier le lien** 
. 

## Si quelque chose n’a pas été sauvé

Tant que les modifications non enregistrées sont ouvertes, **Non sauvegardées** dans
barre d’outils. Si vous fermez ensuite la fenêtre, on vous demandera si la
les changements doivent être abandonnés.
